## How to read a mockup
- **Cyan dashed boxes + number** (annotated images) = a section. The number matches `[n]` in the page spec.
- **Gradient rectangles with a dark silhouette** = video thumbnails (real ones come from YouTube).
- **Cartoon with a cap** = stand-in for Henok's cut-out portrait.
- Stand-in fonts were used by the renderer; build with the real fonts in `docs/02-design-system.md`.
- The `html/*.html` files can be opened in any browser. Resize the window below 700px to see the mobile layout. `html/mock.css` holds exact sizes — translate them into Tailwind.
